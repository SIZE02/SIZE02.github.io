> 蓝桥杯不是"全对才得分"，而是**按测试点给分**。
> 同样的水平，策略好能多拿 20–30 分；策略差可能连省三都危险。

---

## 一、先搞清赛制

- 省赛一般 **4 小时**，约 **10 道题**，满分 **150 分**。
- 通常 **2 道结果填空 + 8 道程序设计**（具体以官网为准）。
- 填空题只看最终答案，不要求代码；编程题按测试点给分。
- **部分分非常重要**：暴力、特判、小数据，都能拿分。
- 只能用标准库，单文件提交。

---

## 二、4 小时时间分配

| 时间 | 任务 | 说明 |
|---|---|---|
| 0–10 min | 通读全卷，标记 A/B/C | A=有把握，B=有思路，C=没思路 |
| 10–35 min | 填空第 1 题 | 填空必须拿满，Python 暴力有优势 |
| 35–60 min | 填空第 2 题 | 卡住就先放着，最后回来 |
| 60–150 min | 前 4 道编程题 | 稳拿基础分，写完立刻测样例 |
| 150–210 min | 中间 3 道 | 先写暴力拿部分分，再想优化 |
| 210–230 min | 最后 1–2 道 | 特判、暴力、输出样例碰运气 |
| 230–240 min | 全面检查 | 输入输出、边界、保存、重复提交 |

**原则**：

- **不要在一道题上卡超过 40 分钟**。卡住就换题，回来可能就有思路。
- **先拿分，再优化**。能过 60% 的暴力，比 0 分的最优解强。
- **每 60 分钟看一次表**，防止前松后紧。
- 最后 10 分钟不要再改大代码，只检查。

---

## 三、选题策略

1. **填空题优先**：通常最简单，且 Python 可以暴力算。
2. **先做 A 类题**：确保会做的分全部拿到。
3. **B 类题先写暴力**：过小数据，拿 30–60%，再考虑优化。
4. **C 类题最后碰**：直接特判小范围 / 输出样例，不要投入超过 10 分钟。
5. **不要按题号顺序死磕**：第 8 题可能比第 5 题简单。

---

## 四、填空题技巧

填空题只交答案，**不要求代码质量和复杂度**，这是 Python 的主场。

常用手段：

- **直接暴力**：10^6、10^7 的循环，Python 也能跑。
- **`itertools`**：全排列、组合、笛卡尔积。
- **`datetime`**：日期推算。
- **大整数**：Python 原生支持，`2**1000`、`math.factorial(100)` 直接算。
- **手算 + 代码验证**：先推公式，再用代码验算。
- **注意答案格式**：整数、字符串、日期、几位小数；题目要求什么就交什么。
- **不要多打空格/换行**。

**填空题失分最常见原因**：

- 看错题目（求的是 1..n 还是 0..n-1）；
- 边界漏算（包含/不包含）；
- 答案格式不对；
- 没验证，交了个近似值。

## 五、暴力与部分分

### 5.1 先写暴力

大多数题都可以写一个 O(2^n)、O(n²)、O(n³) 的暴力：

```python
# 例：n <= 20 的子集枚举
for mask in range(1 << n):
    total = 0
    for i in range(n):
        if (mask >> i) & 1:
            total += a[i]
    if total == target:
        ans += 1
```

- n ≤ 20：2^n 暴力；
- n ≤ 100：O(n³)；
- n ≤ 5000：O(n²)；
- n ≤ 10^5：必须 O(n log n) 或 O(n)。

### 5.2 特判骗分

- 题目有多个子任务时，针对小数据写特判；
- 只有一种特殊情况（如全是 0、n=1）时，直接输出；
- 图不连通、无解的情况，按题目要求输出。

### 5.3 输出样例

实在不会，最后 5 分钟可以输出样例答案碰运气。**不要花超过 5 分钟**，也不要把已经拿到的分改坏。

### 5.4 分段提交

如果比赛系统支持多次提交，可以先交暴力保底，再改优化版。**每次提交前备份当前代码。**

## 六、对拍

用于检查"正解"是否写错。三个文件：

**gen.py**（生成随机小数据）

```python
import random

n = random.randint(1, 10)
print(n)
print(*[random.randint(-10, 10) for _ in range(n)])
```

**brute.py**（暴力，保证正确）

```python
import sys

data = list(map(int, sys.stdin.buffer.read().split()))
n = data[0]
a = data[1:1 + n]

ans = 0
for i in range(n):
    for j in range(i, n):
        if sum(a[i:j + 1]) > 0:
            ans += 1
print(ans)
```

**solve.py**（你的正解）

```python
import sys

data = list(map(int, sys.stdin.buffer.read().split()))
n = data[0]
a = data[1:1 + n]

# 你的算法
print(0)
```

**run.py**（对拍器，跨平台）

```python
import subprocess
import sys

for i in range(1, 1001):
    inp = subprocess.check_output([sys.executable, "gen.py"])
    out1 = subprocess.check_output([sys.executable, "brute.py"], input=inp)
    out2 = subprocess.check_output([sys.executable, "solve.py"], input=inp)
    if out1.strip() != out2.strip():
        print("WA on test", i)
        with open("bad_input.txt", "wb") as f:
            f.write(inp)
        print(inp.decode())
        print("brute:", out1.decode().strip())
        print("solve:", out2.decode().strip())
        break
else:
    print("all ok")
```

**用法**：

```bash
python3 run.py
```

对拍数据要**小**（n ≤ 10），否则暴力太慢；同时覆盖边界：n=1、全相同、全负数、有重复。

## 七、提交前检查清单

每道题提交前，逐条过：

- [ ] 样例过了吗？
- [ ] n=1 会怎样？
- [ ] n=0 / 空输入会怎样？（如果允许）
- [ ] 全是相同元素 / 全负数 / 全 0 会怎样？
- [ ] 数组下标有没有越界？
- [ ] 递归深度会不会爆？
- [ ] 多组数据有没有清空全局数组？
- [ ] 输出格式：换行、空格、大小写、取模？
- [ ] 有没有多余调试输出？
- [ ] 代码保存了吗？

## 八、常见失分点

| 失分点 | 例子 | 对策 |
|---|---|---|
| 读题漏条件 | 要求字典序最小，没看到 | 读两遍，划出关键词 |
| 下标 0/1 混用 | 并查集、树状数组 | 固定约定，写注释 |
| 边界 | n=1、空、全相同 | 每次造边界数据 |
| 递归爆栈 | 10 万节点链 | 改迭代 / BFS |
| 死循环 | 二分 `mid` 不推进 | 检查 `lo/hi` 更新 |
| 浮点误差 | 判等、开方 | 用 `isqrt` / 容差 |
| 输出多余空格 | `print(*a, " ")` | 用 `join` |
| 多测不清空 | 全局数组残留 | 每组重新初始化 |
| 取模漏了 | 大数答案 | 读题确认是否取模 |
| 超时 | O(n²) 跑 10^5 | 先算复杂度 |
| 变量覆盖 | `i`、`j` 重复使用 | 起有意义的名字 |
| 排序写错 | `a = a.sort()` | 记住返回 None |
| 文件没保存 | 比赛系统卡顿 | 频繁 Ctrl+S |

## 九、Python 赛场提速

考前把这几条背下来：

1. **快读**：`sys.stdin.buffer.read().split()`。
2. **快写**：`sys.stdout.write("\n".join(...))`。
3. **局部变量**：热循环里把 `len(a)`、`a` 绑到局部。
4. **内置函数**：`sum`、`min`、`max`、`sorted` 是 C 实现。
5. **列表推导式** 优于 `append` 循环。
6. **成员判断用 set/dict**，不要用 list。
7. **队列用 deque**，不要 `list.pop(0)`。
8. **避免深递归**：改 BFS/迭代。
9. **字符串拼接用 join**。
10. **预处理**：前缀和、筛法、记忆化。
11. **能 O(n log n) 不 O(n²)**；n=10^5 时 O(n²) 必死。
12. **不要用 numpy**。

> 经验值：Python 大约 10^7 次简单操作/秒（视机器），超过 10^8 基本超时。先估复杂度，再写。

## 十、考前一周

### 学习

- 不再学新算法，只做三件事：**真题套卷、错题重做、模板默写**。
- 每天 1 套轻量模拟（2 小时）或半套（填空 + 前 4 题）。
- 晚上 30 分钟默写模板：快读、二分、前缀和、并查集、BFS、01 背包、Dijkstra。

### 作息

- 按比赛时间调整：比赛一般上午 9:00–13:00，提前一周在这个时间段做套卷。
- 不熬夜；考前两天保证 7–8 小时睡眠。
- 考前一天不做难题，只复习错题和模板。

### 物资

- 身份证/学生证、准考证（按官网要求）。
- 提前确认考场、设备、编译器/编辑器。
- 看清是否允许带纸质资料（一般不允许）。
- 比赛当天吃早饭，少喝水。

## 十一、心态

- **目标是把会做的分拿到，不是满分。** 省赛 150 分，拿到 90–105 就很有竞争力。
- **卡住是正常的。** 4 小时 10 题，没有人能全部轻松做完。
- **不要和旁边的人比进度。** 他可能在做第 3 题，也可能第 3 题已经 WA 了 5 次。
- **每道题都有分。** 不会正解就写暴力，不会暴力就特判，不要空着。
- **最后 10 分钟只检查，不改大逻辑。**

## 十二、考场速查卡（可以考前再看一遍）

```
1. 读入：data = sys.stdin.buffer.read().split()
2. 输出：sys.stdout.write("\n".join(map(str, ans)))
3. 复杂度：n=1e5 -> O(n log n)；n=1e6 -> O(n)
4. 先暴力，后优化；先拿分，再完美
5. 每题必测：样例、n=1、全相同、边界
6. 递归深度：sys.setrecursionlimit(1000000)
7. 排序：a.sort(key=...)；不要 a = a.sort()
8. 二分：min 用 (lo+hi)//2，max 用 (lo+hi+1)//2
9. 并查集：find + 路径压缩 + 按大小合并
10. 背包：01 倒序，完全正序
11. 最短路：非负 Dijkstra，多源 Floyd，无权 BFS
12. 不会就骗分，不空题
```
