> **核心原则**：刷题不是为了"刷完"，而是为了"下次遇到同类题能独立做出来"。
> 一道题做三遍，胜过三道题各做一遍。
>
> **国奖路线（6–8 小时/周）**：P0–P2 每类做 3–5 题，P3 选学单调栈/树状数组/区间 DP；总题量 80–100 道 + 6–8 套真题。线段树、KMP、状压 DP 等国赛内容，省一后再学。

## 二、真题的三遍用法

### 第一遍：限时模考

- 4 小时，计时，不查资料、不看题解。
- 按考场策略做（见 [赛场策略](/2026/11/26/lanqiao-contest/)）。
- 记录：总分、每题得分、卡住的原因。

### 第二遍：分类精做

- 按题型拆开：填空、枚举、搜索、DP、图论……
- 不会的看题解，看完**关掉重写**。
- 把新学到的模板补进 [算法模板库](/2026/11/26/lanqiao-templates/) 或自己的笔记。

### 第三遍：错题重做

- 一周后，遮住题解独立重做。
- 仍然卡住的，标记为"高危题"，两周后再做一次。
- 考前只看错题本和高危题。

> **不要**把真题留到最后"舍不得做"。真题是最好的教材，越早开始越好。

## 四、刷题方法

### 20 分钟规则

1. 读题，想 20 分钟：手推样例、想暴力、想复杂度。
2. 20 分钟没思路 → 看**提示**（不是完整题解）。
3. 40 分钟还写不出 → 看题解。
4. 看完题解，**关掉页面，从零重写**。
5. 重写通过后，写复盘，隔一周再做一次。

### 不要做的事

- 不要一卡住就看题解（会产生"我懂了"的错觉）。
- 不要抄代码后直接下一题（抄完要默写）。
- 不要只做简单题（舒适区刷 100 道不如挑战 20 道）。
- 不要跳过暴力（很多题暴力能拿 30–60% 的分）。

### 一道题做到什么程度算"会了"

- 能独立写出；
- 能说出复杂度；
- 能造出边界数据（n=1、空、全相同、负数）；
- 一周后还能重写出来。

## 七、题型识别表

看到题，先归类，再想模板：

| 题目特征 | 优先想 |
|---|---|
| 求方案数 / 最值，且有"选或不选" | DP / 搜索 |
| 最少步数、扩散 | BFS |
| 连通块、能否到达 | DFS / BFS / 并查集 |
| 区间和、区间修改 | 前缀和 / 差分 / 树状数组 / 线段树 |
| "最小的最大值""最大的最小值" | 二分答案 |
| 第 k 大、动态取最值 | 堆 |
| 下一个更大/更小 | 单调栈 |
| 滑动窗口最值 | 单调队列 |
| 排列/组合/子集枚举 | 回溯 / itertools |
| 日期、进制、大整数 | 模拟 + Python 大整数 |
| 字符串匹配 | KMP / 哈希 |
| 最短路 | Dijkstra / Floyd / BFS（无权） |
| 最小生成树 | Kruskal / Prim |
| 依赖关系、先后顺序 | 拓扑排序 |
| 树上选点/子树统计 | 树形 DP / DFS |
| 结果对 10^9+7 取模 | 快速幂 / 组合数 / 矩阵快速幂 |
| n ≤ 20 且要枚举状态 | 状压 DP / 暴力搜索 |
| n ≤ 500 的多源最短路 | Floyd |

## 九、常见误区

1. **"我要先把 Python 学完再刷题"** —— 学不完。第 3 天就开始做题。
2. **"这道题我看懂了"** —— 看懂 ≠ 写出。关掉题解重写。
3. **"真题要留到最后做"** —— 真题是教材，越早越好。
4. **"难题不会，先做简单题"** —— 一直做简单题，考场上还是只会简单题。
5. **"暴力太low，我要写最优解"** —— 考场上先拿分，再优化。暴力能过 60% 的测试点。
6. **"Python 慢，这题肯定过不了"** —— 先算复杂度，实在不行换算法；很多题 Python 时限是放宽的。
7. **"模板背了就行"** —— 模板要会改，边界、下标、取模都得自己调。
8. **"我刷了 500 题"** —— 独立 AC 多少？错题重做了吗？一周后还会吗？

## 十、最低完成线（国奖路线）

如果时间不够，至少完成：

- 洛谷入门 + 普及− 共 **80–100 题**；
- 蓝桥杯省赛真题 **6–8 套**（优先 2022–2026）；
- 每个核心模板配 **3 道题**：二分、前缀和、并查集、BFS/DFS、01 背包、Dijkstra；
- 错题本里 🔴 题全部清零。

做到这些，省一有竞争力；省一后再加国赛专题和国赛真题。不要为了“刷完”牺牲考研。
