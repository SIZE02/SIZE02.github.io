> 本文整理了 Redis 缓存、持久化、分布式锁等高频面试题。

## 1. 常用数据类型和场景？

String（缓存、计数器）、Hash（对象）、List（消息队列）、Set（去重、抽奖）、ZSet（排行榜）。

## 2. Redis 为什么快？

① 纯**内存**操作；② **单线程**避免上下文切换；③ **IO 多路复用**；④ 高效的数据结构。

## 3. 缓存穿透？怎么解决？

查询**不存在的数据**，请求打到数据库。
解决：① 缓存空值；② **布隆过滤器**。

## 4. 缓存击穿？怎么解决？

**热点 Key 过期**瞬间，大量请求打到数据库。
解决：① **互斥锁**；② 热点数据**永不过期**。

## 5. 缓存雪崩？怎么解决？

**大量 Key 同时过期**，或 Redis 宕机。
解决：① 过期时间加**随机值**；② 搭建**集群**；③ 服务**熔断降级**。

## 6. Redis 持久化机制？

- **RDB**：定时快照，恢复快，可能丢数据。
- **AOF**：记录写命令，数据安全，恢复慢。

## 7. 过期策略和内存淘汰策略？

过期策略：**惰性删除 + 定期删除**。
淘汰策略：**LRU、LFU、Random**、TTL 等 8 种，默认 `noeviction`。

## 8. 如何用 Redis 实现分布式锁？

`SET key value NX EX` 加锁，value 存唯一标识；释放时用 **Lua 脚本**判断是自己的锁再删。

## 9. Redis 主从复制原理？

从节点 `SLAVEOF` 主节点 → 主节点 **RDB 全量同步** → 后续 **AOF 增量同步**。

## 10. Redis 集群方案？

① **主从复制**；② **哨兵模式**（自动故障转移）；③ **Cluster 分片集群**（数据分片）。
