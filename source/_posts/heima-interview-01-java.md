> 本文整理了我复习 Java 基础时的高频面试题，涵盖集合、多线程、JVM 等核心知识点。

## 1. == 和 equals() 的区别？

- `==` 比较的是**内存地址**（基本类型比较值）。
- `equals()` 默认也是比较地址，但 String、Integer 等类重写了它，变成**比较内容**。

## 2. ArrayList 和 LinkedList 的区别？

- ArrayList 底层是**数组**，查询快、增删慢。
- LinkedList 底层是**双向链表**，查询慢、增删快。

## 3. HashMap 的底层原理？JDK1.8 优化了什么？

底层是**数组 + 链表 + 红黑树**。JDK1.8 在链表长度超过 8 且数组长度 ≥ 64 时，会把链表转成**红黑树**，查询效率从 O(n) 提升到 O(logn)。

## 4. HashMap 和 ConcurrentHashMap 的区别？

- HashMap **线程不安全**，多线程下可能死循环。
- ConcurrentHashMap **线程安全**，JDK1.8 用 **CAS + synchronized** 锁单个桶，并发性能高。

## 5. 多线程的创建方式有哪几种？

① 继承 Thread 类；② 实现 Runnable 接口；③ 实现 Callable 接口 + FutureTask；④ 使用线程池。

## 6. synchronized 和 Lock 的区别？

- synchronized 是**关键字**，自动加锁释放锁。
- Lock 是**接口**，需要手动 `lock()` 和 `unlock()`，但更灵活，支持**公平锁、可中断、超时**。

## 7. 线程池的核心参数有哪些？执行流程？

核心参数：核心线程数、最大线程数、空闲存活时间、时间单位、阻塞队列、线程工厂、拒绝策略。

执行流程：核心线程满 → 进队列 → 队列满 → 开新线程到最大数 → 还满 → 触发拒绝策略。

## 8. JVM 内存结构？

堆（对象）、虚拟机栈（方法局部变量）、本地方法栈、方法区（类信息、常量）、程序计数器。

## 9. 垃圾回收机制？常见回收器？

GC 通过**可达性分析**判断对象是否存活。常见回收器：Serial、ParNew、Parallel Scavenge、CMS、G1。JDK9 后默认 G1。

## 10. 面向对象三大特性？

**封装**（隐藏细节）、**继承**（复用代码）、**多态**（父类引用指向子类对象，一个接口多种实现）。
