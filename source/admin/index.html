连接 GitHub

后台不需要单独服务器。保存文章时，会使用你的 GitHub Token 直接提交到 SIZE02/SIZE02.github.io，随后自动触发 GitHub Pages 更新。

  1. 打开 GitHub Fine-grained Token 创建页面。
  2. Token 名称可填 size02-blog-admin，有效期建议 90 天。
  3. Repository access 选择 Only select repositories，只勾选 SIZE02.github.io。
  4. Permissions 中把 Contents 设为 Read and write。
  5. 生成后复制 Token，粘贴到下面。Token 只保存在当前浏览器。
